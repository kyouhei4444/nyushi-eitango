# 山梨入試 英単語

山梨県の公立高校入試に向けて、英単語・熟語をスマホで覚えるためのアプリです。
HTMLファイル1つで動きます。インストールやアカウント登録はいりません。

## 使い方

### スマホでそのまま開く
次のURLをスマホのブラウザで開きます。

https://kyouhei4444.github.io/nyushi-eitango/

ホーム画面に追加しておくと、単語カードのアイコンからアプリと同じように起動できます。
アプリのホーム画面に「ホーム画面に追加しよう」の案内が出ます。

- Android（Chrome）：案内の **「ホーム画面に追加」ボタン** を押す
- iPhone（Safari）：画面下の共有ボタン（□に↑）→「ホーム画面に追加」
- LINE などのアプリ内で開いたとき：「ブラウザで開く」で開き直してから追加する

一度開いておけば、電波のない場所でも学習できます。

### ダウンロードして使う
1. このページの緑色の「Code」ボタン →「Download ZIP」
2. ZIPを展開して、`index.html` をブラウザで開く

## できること

- **カードで覚える**：単語カードをめくって答えを見て、「覚えた／まだ」を自分で付けます。
- **4択テスト**：意味を選びます。英語→日本語と日本語→英語のどちらの向きでも出せます。
- **スペル練習**：日本語を見て英単語を入力します（英作文・記述問題の対策用）。
- まだ出ていない語、苦手な語、そろそろ復習する語を優先して出題します。
- 品詞・レベル（基本／標準／発展）で出題範囲を絞れます。「苦手な語だけ」にもできます。
- 英語を読み上げます（端末の音声機能を使うので、機種によっては鳴りません）。
- 単語一覧の画面で、検索と「苦手／覚えた／まだ」の絞り込みができます。

## 収録している単語

英単語・熟語 389語。どの語にも例文と和訳を付けています。不規則動詞には変化形も載せています。

| レベル | 目安 |
|--------|------|
| 基本 | 中1〜2で習う必須語 |
| 標準 | 入試によく出る語 |
| 発展 | 長文・英作文で差がつく語 |

単語は、中学校の学習範囲と一般的な入試頻出語をもとに選んでいます。
山梨県の過去問を集計したものではありません。レベル分けも作成者の判断です。

## 学習記録の保存

学習記録は、使っている端末のブラウザの中に保存されます。

- 別の端末やブラウザとは共有されません。
- ブラウザの履歴やサイトデータを消すと、記録も消えます。
- プライベートブラウズ（シークレットモード）では保存されません。

## ファイル構成

```
index.html             アプリ本体（単語データもこの中）
manifest.webmanifest   ホーム画面に追加したときの名前・アイコン
sw.js                  オフラインで使えるようにするしくみ
icons/                 アプリのアイコン
```

## 単語を追加・修正するには

`index.html` の中の `RAW` に、1行1語で書いてあります。

```
単語|意味|例文|例文の訳|レベル(A=基本 B=標準 C=発展)|不規則変化(任意)
choose|選ぶ|Choose one from these books.|これらの本から1冊選びなさい。|B|chose-chosen
```

`#動` `#名` `#形` `#副` `#前` `#熟` の見出しの下に書いた語が、それぞれの品詞として扱われます。
